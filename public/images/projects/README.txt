Taruh screenshot proyek kamu di sini, contoh:
- project-1.jpg
- project-2.jpg
- project-3.jpg

Nama file harus sama persis dengan yang ditulis di
src/components/projects/projects.jsx (field "image").

Kalau file belum ada / belum diisi, kartu proyek otomatis
menampilkan fallback nomor urut, jadi tidak akan rusak tampilannya.

Rasio gambar yang disarankan: 16:10 (misalnya 1280x800px) biar pas
dengan crop di kartu proyek.
